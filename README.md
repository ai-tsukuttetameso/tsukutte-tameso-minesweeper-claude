# つくってためそ 地雷さがし（Claude版）

YouTube「AIでつくってためそ」第4回のために、AI（Claude）が作ったブラウザで遊べる地雷さがしゲームです。

▶ **遊ぶ：** https://ai-tsukuttetameso.github.io/tsukutte-tameso-minesweeper-claude/

## できること

- 初級（9×9・地雷10）／中級（16×16・地雷40）／上級（30×16・地雷99）
- 右クリック（スマホは長おし、または「🚩 はた」モード）で旗、もう一度で「？」
- 数字のマスをクリック、または左右同時クリックで、まわりをまとめて開く
- 残り地雷数・経過時間・難易度ごとのベストタイム（この端末の中だけに保存）
- 🤖 **AIにおまかせ**：コンピューターが1手ずつ考えて解きます
- ゲームオーバーの演出は、思いきり派手に
- スマホ対応（縦長の画面では、上級の盤を縦向きに並べかえます）
